## Проект

**Что:** прототип цифровой платформы АПК «Код Урожая» на LSfusion.
**Где:** VirtualBox VM (ALT Linux), `/home/vboxalt/mite_dev`.
**Как доступаться:** SSH `127.0.0.1:2222`, веб `http://<IP>:8080/main`.
**VCS:** fossil (`~/mite_dev/mite.fossil`). **НЕ коммитить в git `sources/mite_public`** — это чужой проект (MITE).

## Спецификация и ПМИ

- `docs/spec-source.md` — полная спецификация (эталон требований)
- `docs/pmi-source.md` — ПМИ, 10 контрольных примеров (КП01–КП10)

## Модули (все в `src/main/lsfusion/ku/`, namespace `Ku`)

| Модуль | Что делает |
|---|---|
| `KuCrop` | НСИ культур + правила севооборота |
| `KuLand` | земельный банк, договоры, взаиморасчёты, **интерактивная карта** |
| `KuRotation` | план севооборота (матрица поле×год), валидация, REST |
| `KuTechCard` | техкарты + 6 справочников |
| `KuProdPlan` | годовой план, акт урожая |
| `KuBudget` | цены, МТР, БДР, БДДС |
| `KuYield` | NPK-баланс, сезонные ТК, коррекции, предписания |
| `KuSimulation` | модель KuGDD, сценарный анализ |
| `KuAnalytics` | панели, дашборд, сквозной процесс |

Подключены через `KuApp` → `MiteApp` (topModule).

## Платформенные правила lsFusion (критично!)

1. Один `REQUIRE` на модуль.
2. `WHERE` не существует — только `IF`/`AND`.
3. `CASE n WHEN 1` не работает — только `CASE WHEN n = 1 THEN`.
4. Фигурные скобки `{}` в строках — локализация. JSON не строится на сервере.
5. Свойство с одним именем — один модуль (нет перегрузки).
6. `EXPORT xlsx FROM` не поддерживается — только `PRINT форма XLSX`.
7. `WHEN SET` затирает присвоения в NEW-блоке — статусы дозаправкой.
8. `LOCAL` после `APPLY` не живёт — только lookup по коду.
9. Большой `GROUP CONCAT` из CASE/OVERRIDE → SQL-взрыв — собирать императивно.
10. ABSTRACT-действия для кнопок на формах, если реализация PRINT'ит форму.
11. **Русский UI при любой локали браузера** (27.09): `lsfStrLiteralsLanguage=ru`
    превращает русские литералы в i18n-ключи, значения клиенту отдаются по его
    локали из `*ResourceBundle.properties`. Поэтому default-слот (файл без
    суффикса `_ru`) НЕ должен содержать английских переводов:
    `MiteResourceBundle.properties` = копия `_ru`; `MiteSystemResourceBundle.properties`
    (новый) = русские значения системных ключей платформы (наш jar первый в
    classpath, `DefaultLocalizer` берёт первый bundle с `containsKey`).
    Иначе клиенты с en-браузером видят «Data», «Devices», «Administration».
    Новые литералы — дополнять ОБА файла одинаково (default = русский).

Полный список: `docs/09-architecture.md`, раздел «Платформенные особенности».
