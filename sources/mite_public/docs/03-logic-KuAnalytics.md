# 03-logic. KuAnalytics — отчёты и дашборды (`Analytics.lsf`)

> Модель — `02-data-model.md` §10 (новых сущностей нет). Источник —
> СТ модуль «Отчётность и аналитика» в части прототипа (ФТ.REP.1–6,
> ФТ.GEO.1–6 — статус У; ETL/DWH — О). Eталоны: Jasper
> `reports/*.jrxml`, Grafana `organization/grafana/*`.

## 1. Jasper-отчёты (ФТ.REP — предопределённая библиотека)

| Отчёт | Источник | Параметры |
|---|---|---|
| «Земельный банк» | LandPlot+LeaseContract | организация, статус |
| «Сальдо аренды» | LeaseEntry | период |
| «План севооборота» (матрица) | RotationPlan | план |
| «Годовой план» | ProdPlan+items | план |
| «МТР-план» | MtrPlan | план |
| «БДР/БДДС» | BudgetPL/CF | бюджет |
| «Урожайность: план vs факт» | HarvestAct | год, культура |
| «Прогноз симуляции» | SimResult | результат |

Реализация: `PRINT`-действия, шаблоны в
`src/main/lsfusion/reports/Ku_*.jrxml` (образец — `Mite_routeReport.jrxml`);
запуск из форм соответствующих модулей (кнопка/пункт).

## 2. Grafana-дашборды (ФТ.REP/GEO — визуальная аналитика)

По образцу `GrafanaDashboard` (создание из логики, шаблоны
`resources/grafana/Ku_*.json`):
- `Ku land` — участки/договоры/сальдо по организациям;
- `Ku budget` — доход/расход/маржа по месяцам, сценарии;
- `Ku yield` — прогнозы симуляции по полям (базовый vs сценарный).
Данные — через существующий механизм измерений MITE (GrafanaMeasurement)
не подходят: для прототипа Grafana-дашборды строятся поверх прямых SQL
витрин (view) — создать простые SQL view в migration.script:
`ku_v_rotation`, `ku_v_budget`, `ku_v_yield` (⚠ допущение; полноценные
витрины DWH — 05). Если быстрое подключение view к Grafana потребует
драйвера — ограничиться Jasper + веб-формами сводок, решение при
генерации зафиксировать в ServiceLog.

## 3. Веб-сводки (штатные формы)

Дашборд-формы агрегатов (без Grafana): «Код Урожая — сегодня»:
площадь по культурам, планы (статусы), сальдо аренды, отклонения
урожайности, активные симуляции — вычисляемые GROUP-агрегаты по
модулям Ku* (⚠ лёгкие агрегаты, §5 00-context; HTML-KPI-блок по
образцу `Agro.lsf:298`).

## 4. Гео-часть (ФТ.GEO — У)

Сводка «Поля на карте»: таблица полей с координатами + ссылка на
внешнюю карту (ПКК/OSM по centerLat/centerLon) — без встроенного
картографического движка (05). NDVI/треки — 05.

## 5. Критерии приёмки

1. Каждый отчёт открывается из своей формы и печатается (PDF).
2. Дашборд-форма «Код Урожая — сегодня» показывает живые агрегаты
   сид-данных.
3. Grafana-дашборд хотя бы один создаётся из логики (или
   зафиксированное решение об отсрочке — тогда пометка в 05).
