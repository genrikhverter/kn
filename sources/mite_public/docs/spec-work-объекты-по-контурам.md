## 1. Порядок появления сущностей по сценарию

Сквозной процесс спецификации начинается с земельного банка, но у него есть неявный
«нулевой контур» предусловий — в прототипном сквозном сценарии (акты 0–14) он зафиксирован
явно: акт 0 «Развёртывание контура и ролевая модель», акт 1 «НСИ и правила».

### Контур 0 — предусловия (спекой как шаг не описан)

| Порядок | Сущность | Зачем нужна дальше |
|---|---|---|
| 1 | **Организация** (холдинг) | владелец всех данных, RLS-граница |
| 2 | **Пользователь + Роль** (акт 0: 9 ролей КУ) | акторы всех шагов |
| 3 | **НСИ агрономии**: Культура (+ правила предшественников/табу, BBCH-стадии, пороги стрессов, регионы допуска), Тип почвы | севооборот (шаг 2), поле, NPK (шаг 6) |
| 4 | **НСИ производства**: Виды работ, Фазы развития, Номенклатура, Ед. изм., Методы внесения, Профессии, Сорт | техкарты (шаг 3), NPK |

### Контур I — годовое планирование (шаги 1–5)

| Шаг | Сущности в порядке появления |
|---|---|
| **1. Земельный банк** | **Контрагент** (арендодатель) → **Земельный участок** (кадастровый номер, контур, ЕГРН) → **Договор аренды** (+уведомления, взаиморасчёты: записи, ведомости, заявки на ДС) → **Поле + Состав поля** → **Агрохиманализ** |
| 2. Севооборот | Долгосрочный план севооборота (+строки-матрица, нарушения, версии) |
| 3. Техкарты | Технологическая карта (+операции, материалы, ГСМ, труд) |
| 4. Годовой план | Годовой производственный план (+строки «поле×культура×ТК») |
| 5. Деньги | Сценарий цен → МТР, БДР, БДДС |

### Контур II — сезонный (шаги 6–11)

Комплексный план (+баланс NPK) → Сезонная ТК → Файл-предписание → Задача симуляции →
Результат моделирования (ряды точек) → Стресс-событие → Рекомендация коррекции →
Сессия оптимизации (+заявка МТР, маршрутное задание) → Акт учёта урожая.

### Контур III — аналитика и замыкание (шаги 12–13)

Конвейер ETL / импорт-файл → DWH (измерения, факты) → Витрины → Шаблон отчёта →
Сессия калибровки (+предложения коэффициентов).

**Первые сущности сценария:** Организация, Пользователь/Роль и НСИ (контур 0), далее в
контуре I: **Контрагент → Земельный участок → Договор аренды → Поле → Агрохиманализ**.

## 3. Замечания и статус разбора

1. **Итого:** ~75 бизнес-объектов (контур 0 — 18, I — 22, II — 19, III — 13, сквозные — 8).
2. Спецификация не описывает контур 0 как шаг процесса (справочники «висят» в модулях,
   организация/пользователи — вне рамок). Кандидат: зафиксировать в спеке отдельным шагом 0.
3. Поле и Агрохиманализ в спеке отнесены к разным модулям (справочник полей — модуль
   планирования, агрохиманализ — земельный банк), а сценарно рождаются вместе в шаге 1 —
   границы модулей спеки и сценария не совпадают.
4. Значительная часть инфраструктуры (★) существует только в коде — шина, аудит, задания,
   телеметрия, карантин: спека v1 их не описывает (в v2 они есть как ФТ7/ФТ8, но не как сущности).
