# 03-logic. KuBudget — цены и бюджеты (`Budget.lsf`)

> Модель — `02-data-model.md` §6. Источник — СТ ФТ1.4.1–1.4.3,
> ФТ1.5.1–1.5.3 + сущности. Статусы: сценарии цен — П; бюджеты — У
> (без внешних фининтеграций). Все формулы распределения по месяцам —
> ⚠ допущения прототипа (уточнить экономистом).

## 1. Сценарии цен (ФТ1.4.1–1.4.3)

- `newPriceScenario`: NEW draft, строки цен из номенклатуры (копия
  `basePrice` как стартовое значение).
- Редактирование/утверждение: только draft; `approvePriceScenario` →
  approved + ServiceLog; CONSTRAINT: цена > 0.
- Новая версия (ФТ1.4.3): `copyPriceScenario (s, name, factor?)`: draft,
  `basedOn <- s`, цены = цены(s) × factor (если задан; РСТ
  «коэффициент копирования»), `version <- version(s)+1`; при утверждении
  старая → archived. CONSTRAINT: период действия новой внутри периода
  старой не проверять (прототип).
- Расчётные: `price (PriceScenario s, Nomenclature n) = GROUP MAX
  price(PriceScenarioItem) WHERE scenario=s AND nomenclature=n` —
  основная точка потребления для бюджетов и KuYield.

## 2. Расчёт МТР-плана (ФТ1.5.1, часть)

`calculateMtrPlan (MtrPlan m)`: FOR операций ТК всех items годового
плана m.prodPlan:
- материал: `qty = rate(OperationMaterial) × areaHa(item)`; месяц —
  по `dateFrom` операции (если задана), иначе равномерно на 12 месяцев
  (⚠ допущение);
- ГСМ: аналогично по `OperationFuel`.
Группировка: (monthNo, nomenclature) — `GROUP SUM` в MtrPlanItem
(перед расчётом DELETE items плана). Статус: draft → calculated.
Цены не участвуют (МТР в натуральных величинах).

## 3. Расчёт БДР (ФТ1.5.1)

`calculateBudgetPL (BudgetPL b)`: DELETE items; FOR планов-назначений:
- Расходы: материалы/ГСМ из техкарт × площадь × `price(priceScenario,
  nomenclature)`; месяц как в §2. Статьи: подбор CostItem по группе
  номенклатуры (`Удобрения` → статья «Удобрения» и т.п. — маппинг
  групп в сид-справочнике, ⚠ допущение); ФОТ: `timeRate × workersCount?
  × площадь × 500 руб/ч` (⚠ ставка-константа из Options, допущение);
- Доходы: FOR items: `targetYield(crop)/10 × areaHa × price(scenario,
  продукция)` — продукция: номенклатура типа «Готовая продукция» с
  привязкой к культуре (в прототипе: сид-строка «Зерно пшеницы» и т.д.,
  связка через `group` номенклатуры = name(crop); ⚠ допущение); месяц —
  месяц уборки (dateFrom последней операции, иначе сентябрь).
Итоги: `GROUP SUM amount BY itemKind` — доход/расход/маржа.

## 4. Расчёт БДДС (ФТ1.5.1/1.5.3)

`calculateBudgetCF (BudgetCF f)` по утверждённому БДР: FOR items БДР:
- расход с условием `deferral N дней`: выплата в месяц статьи + сдвиг
  `N/30` месяцев (округление вниз, ⚠ допущение); `prepay P%`: P% в
  текущий месяц, остальное со сдвигом; `onFact` — без сдвига;
- доход: поступление в месяц реализации + отсрочка по условию контракта
  (в прототипе единое условие из Options, ⚠ допущение).
Строки: (monthNo, moveKind, amount, source=статья/контрагент-строка,
paymentTerm). Итог: сальдо нарастающим итогом (расчётное свойство
`runningBalance` по месяцам).

## 5. Сценарный анализ (ФТ1.5.2)

`recalcWithScenario (BudgetPL b, PriceScenario alt)`: расчёт копии
структуры в памяти невозможен — прототип: пересоздать скрытый
`BudgetPL draft'` с alt-сценарием, сравнение `compareBudgets (b1, b2)`:
формирует строки Δ по статьям/месяцам (доход/расход/маржа), выводится
отдельной формой «Сравнение сценариев» (04-ui). После сравнения черновик
удалять.

## 6. Утверждение (ФТ1.5.3)

`approveMtrPlan/approveBudgetPL/approveBudgetCF`: calculated → approved
(только из calculated; draft нельзя — сначала расчёт). Интеграция с
внешними системами (1С) — 05; вместо неё ServiceLog-запись «готов к
выгрузке».

## 7. Валидации

Цены > 0; месяц 1–12; суммы ≥ 0; БДДС строится только по approved БДР;
нельзя рассчитать план по неутверждённому годовому плану (CONSTRAINT).

## 8. Сид

Сценарий «Базовый 2027» approved (цены на всю сид-номенклатуру),
«Оптимистичный 2027» (×1.15, draft) — для сценарного анализа;
рассчитанные и утверждённые МТР/БДР/БДДС по сид-годовому плану.

## 9. Критерии приёмки

1. Утверждение сценария/версии: archived у старой, version растёт.
2. МТР: контрольный пример — норма 150 кг/га × 100 га = 15000 кг в
   месяце операции.
3. БДР сходится: сумма материалов = Σ(rate×area×price).
4. БДДС: отсрочка 30 дней сдвигает выплату на месяц.
5. Сравнение сценариев показывает Δ маржи между «Базовым» и
   «Оптимистичным».
