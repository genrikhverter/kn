# 14. Контуры полей на карте: источники и как наносить самостоятельно

> Реалистичность полигона = реальная геометрия угодья, а не прямоугольник.
> Стенд «Код Урожая» сидит на реальной местности: СКО, район Петропавловска
> (54.9° с.ш., 71.4° в.д.) — поэтому контуры берём из открытых геоданных
> той же местности.

## 1. Что уже сделано на стенде (миграция `sql/08-real-contours-osm.sql`)

| Поля | Источник контура | Вершины |
|---|---|---|
| KH-001…006 «Северное/Южное/Заречное» | эталонная карта KNP (uMap хозяйства), возвращены к 97% исходного масштаба; areaHa синхронизирована с площадью контура | 4–21 |
| KH-007…010 «Луговое/Приозёрное/Балка» | **OpenStreetMap**, way id 1252256271 / 1254823267 / 560747176 / 1258136155 — реальные пахотные участки западнее (71.25–71.30° в.д.), форма сохранена, площадь приведена к areaHa | 32–90 |
| KH-101/102 (демо-RLS «Агро-Север») | OSM, way id 1254823271 / 1254823273 | 69–82 |

Технология переноса: форма → изотропный масштаб до нужной площади
(коэффициент √(S_целевая/S_реальная), с учётом сжатия градуса долготы
на широте 54.9°) → параллельный перенос в точку размещения → проверка
попарных пересечений (сегментный тест; тест вложенности вершины даёт
ложные срабатывания на общих кадастровых границах).

## 2. Как найти реальный контур самостоятельно

### 2.1. OpenStreetMap / Overpass (весь мир, бесплатно)

В браузере: <https://overpass-turbo.eu> → Wizard → запрос:

```
landuse=farmland in "Северо-Казахстанская область"
```

или bbox-запросом (юго-запад, северо-восток):

```
[out:json][timeout:90];(way["landuse"="farmland"](54.78,71.15,55.02,71.60););out geom;
```

Export → GeoJSON. Прямой API (зеркала, основной overpass-api.de бывает
капризен — зеркалу maps.mail.ru нужен User-Agent):

```bash
curl -s "https://maps.mail.ru/osm/tools/overpass/api/interpreter" \
  -H "User-Agent: my-app/1.0" \
  --data-urlencode 'data=[out:json];(way["landuse"="farmland"](юг,запад,север,восток););out geom;' \
  -o farmland.json
```

В QGIS то же — плагин **QuickOSM**: ключ `landuse`, значение `farmland`,
extent с карты; слой → правый клик → Export → GeoJSON.

### 2.2. РФ: публичная кадастровая карта (Росреестр)

<https://pkk.rosreestr.ru> — найти участок по кадастровому номеру,
инструменты-надстройки браузера (например, «ПКК-граббер») выгрузляют
контур в GeoJSON. Юридически точный источник границ (в отличие от OSM,
где farmland — фактическая распашка).

### 2.3. Рисование вручную по спутнику

- <https://geojson.io> — кликами по спутниковой подложке Mapbox, экспорт
  GeoJSON; умеет открывать/править наш файл напрямую.
- Google Earth Pro — «Добавить полигон», экспорт KML → конвертация
  `kml → geojson` (QGIS или `ogr2ogr -f GeoJSON out.geojson in.kml`).
- QGIS + подложка «QuickMapServices → Google Satellite» — оцифровка
  с трассировкой (автодоводка по спутнику).

## 3. Формат, который ждёт система

Поле: `ku_field.ku_boundarygeojson_field` — GeoJSON Polygon (WGS-84,
одиночное кольцо, замкнутое, 6 знаков после запятой достаточно):

```json
{"type":"Polygon","coordinates":[[[71.34,54.90],[71.35,54.90],…,[71.34,54.90]]]}
```

Центры `ku_centerlat/lon_field` — центроид кольца. У участка
(`ku_landplot.ku_polygongeojson_landplot`) — тот же формат; принято
`контур поля × 1.03` (визуальный кадастровый ореол).

## 4. Перенос контура на место (если поле не в своей точке)

Реальный контур чужого региона переносят: центрируют, масштабируют до
площади поля и смещают в целевую точку — готовый скрипт:
`python3`-функция `transform()` в истории миграции 08 (повторена в
репозитории как `sql/08`), проверка пересечений — сегментный тест.

## 5. Применение и пересчёт

```bash
# на ОСТАНОВЛЕННОМ сервере:
sudo docker exec -i mite_db psql -U postgres -d iot -q < sql/08-real-contours-osm.sql
# после старта — пересчёт зависимых контуров (площади → планы/бюджеты/
# симуляции/витрины), например через /exec:
curl -u admin:fusion "http://localhost:7651/exec?action=Ku.calculateMtrPlan&p=<id МТР>"
curl -u admin:fusion "http://localhost:7651/exec?action=Ku.calculateBudgetPL&p=<id БДР>"
curl -u admin:fusion "http://localhost:7651/exec?action=Ku.calculateBudgetCF&p=<id БДДС>"
curl -u admin:fusion -X POST "http://localhost:7651/exec?action=Ku.refreshKuMap"
```

Проверка площади контура (PostGIS, кв.м → га):

```sql
SELECT ku_code_field,
       round(ST_Area(ST_GeomFromGeoJSON(ku_boundarygeojson_field)::geography)/10000, 1)
FROM ku_field ORDER BY 1;
```
