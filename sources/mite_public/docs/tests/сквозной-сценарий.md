## 1. Назначение и рамки

- **Покрываются все функции, реализованные в прототипе** (по карте
  соответствия ТЗ→код): операционный контур первого уровня целиком,
> аналитический контур в объёме стенда, интеграции — в режиме
  «контракт зафиксирован» (заглушка + журнал, live-выключатель),
  эксплуатационный контур (мониторинг/аудит/бэкап).
- **Не покрывается на стенде** (осознанные исключения спецификации v2.0,
  см. `docs/05-deferred.md`): живой обмен с ФГИС/1С (УКЭП/СКЗИ), ЕСИА/MFA,
  спутниковый NDVI (факт — модельная оценка/импорт), поточная телеметрия
  техники, OLAP-кубы, животноводческие функции (4.2.4.17–19), LLM-генерация
  гипотез калибровки. Для заглушек проверяется: вызов принимается,
  конверт контракта корректен, запись в журнале интеграций создана.
- **Формат:** акты = функциональные блоки; внутри акта — шаги «действие →
  ответ системы» либо ссылка на тест-док этапа (без дублирования).
  Регресс-точки фиксов инспекции 07.10 помечены «регресс фикса».

### А1.7. Журналирование изменений НСИ (аудит, hash-chain)

| № | Действие пользователя | Ожидаемый ответ системы |
|---|---|---|
| 1 | Изменить у «Гречиха тест» целевую урожайность 22.00 → 25.00; сохранить; открыть «Служебное → Журнал изменений (версионирование)» | Верхняя запись: время, пользователь, сущность «Культура», поле «Целевая урожайность», «22.00 → 25.00», № в цепочке `seq`, хеш md5; записи связаны prevHash→hash без пропусков |

| 3 | Изменить коэффициент модели (акт 12) или поле другой НСИ | Новые записи продолжают цепочку; скрытая правка задним числом невозможна |
