## Развёртывание на новой ВМ

Полная инструкция — `sources/mite_public/docs/12-deploy-guide.md`
(с настройки ОС; написана по факту развёртывания 04.10.2026).
Кратко:

```bash
tar xzf mite_dev.tar.gz -C ~/ && sudo chown -R $USER:$USER ~/mite_dev
# Docker + Compose v2 должны быть установлены; пользователь — в группе docker
cd ~/mite_dev/sources && git clone https://github.com/lsfusion/platform.git
cd platform && git checkout 2221b1992f3b          # пин платформы
cd ~/mite_dev/docker && docker compose build && docker compose run --rm builder
docker compose up -d db server grafana web         # старт ~1.5 мин
# данные демо-стенда — восстановить из backups/*.gz (процедура — 08-operations §4а)
# cron бэкапов: crontab -e → 30 2 * * * ~/mite_dev/backup_db.sh
```

- веб-клиент: `http://<IP-ВМ>:8080/main`, Grafana: `:3000`
- `admin`/`fusion` — администратор; **демо-логины показа**: `demo.agronom`/`demo`,
  `demo.banker`/`demo` (разграничение разделов включено после входа под ролью)
